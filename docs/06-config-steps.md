# 06 - Configuration Steps

Configuration path in the IMG: **Extended Warehouse Management**. Record each step with the path, the values and a screenshot.

| # | Step | Result |
|---|------|--------|
| 1 | Define warehouse number | WH01 created |
| 2 | Assign warehouse number to plant and storage location (ERP integration) | Delivery distribution works |
| 3 | Define storage types | High rack, fixed bin, GR area, GI area |
| 4 | Define storage sections and bin types | Sections and bin types available |
| 5 | Create storage bins | Bins created with master data upload |
| 6 | Define activity areas | Areas for putaway and picking |
| 7 | Define putaway control and storage type search sequence | Directed putaway |
| 8 | Define stock removal strategy | FIFO removal |
| 9 | Define warehouse process types and warehouse order creation rules | Tasks and orders created |
| 10 | Define document types and item types for delivery | Inbound and outbound delivery processing |
| 11 | Define packaging specification | Packing works |

Each row gets its own section below as it is completed.

## Template for a completed step
- **Path:** IMG path
- **Settings:** values set
- **Why:** business reason
- **Screenshot:** `screenshots/config/step-XX.png`
